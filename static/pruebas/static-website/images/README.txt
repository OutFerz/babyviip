Carpeta de imágenes de la demo estática.

- **logo.png** — Copia del logo oficial del proyecto (`static/img/logo.png`). El HTML usa `images/logo.png` para que funcione también con `file:///` al abrir `index.html` localmente.

Las PNG antiguas del ejemplo "Café" ya no se usan; puedes borrarlas si quieres limpiar la carpeta.

Si actualizas el logo en `static/img/logo.png`, vuelve a copiarlo aquí para mantener la demo alineada:

  (desde la raíz del repo, ejemplo PowerShell)
  Copy-Item static/img/logo.png static/pruebas/static-website/images/logo.png -Force
